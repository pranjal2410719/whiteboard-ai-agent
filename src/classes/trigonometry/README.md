# Trigonometry & Right Triangles Modular Class

A self-contained, modular class for Trigonometry and right-triangle trigonometric ratios.

## Directory Structure
```
classes/trigonometry/
├── index.ts                 # Class entry point & complete definition
├── board.ts                 # Whiteboard initial cover & 4 chapter scenes
├── intelligence.ts          # Semantic regions (Hypotenuse, Opp, Adj, θ, SOH-CAH-TOA)
├── script.json              # 4 chapter narrations, timestamps, cues, study notes
├── README.md                # Documentation
├── assets/                  # High-res right triangle vector diagram
└── audio/                   # 2-minute lecture audio (trigonometry-v2.mp3)
```

## Features
- **4 Chapter Scenes**:
  1. Right Triangles and Reference Angles (29s)
  2. The Primary Ratios: Sine and Cosine (32s)
  3. Tangent and the SOH-CAH-TOA Memory Tool (31s)
  4. Pythagorean Identity and Real-World Power (28s)
- Total Duration: 120 seconds (2 minutes).
- Synchronized whiteboard ink animations, highlights, and cues.
- Spatial vision intelligence with verified target coordinates for Hypotenuse, Opposite, Adjacent, Angle Theta, and SOH-CAH-TOA.
