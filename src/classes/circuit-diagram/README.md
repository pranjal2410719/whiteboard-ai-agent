## 1. Class Overview & Learning Objectives
Students master direct-current electrical circuits:
1. Identify the essential components (DC voltage battery source, closed switch, resistive load, lamp).
2. Trace conventional current flow from positive (+) to negative (−).
3. Apply Ohm's Law ($V = I \times R$) to calculate current amperage given voltage and resistance.
4. Calculate electrical power dissipation ($P = V \times I$).
